# The Redsmith's Roadmap — Codeforces Red

**Goal**: Codeforces 2400+ (Red)
**Starting point**: Div. 4 A-level, ~44 problems solved, no contest experience
**Language**: Python → C++ (transition at ~1400 rating)

---

## Stage 1 — Foundation (Current → 1000 rating)
**Focus**: Problem-solving habit. Contest exposure. Brute force mastery.

### Topics
- Basic math (modular arithmetic, divisibility, primes up to sqrt)
- String manipulation
- Basic sorting (using built-ins, understanding why)
- Simple greedy (obvious cases only)
- Brute force iteration

### Goals
- Participate in 10 Codeforces Div. 4 rounds
- Consistently solve A + B in contests
- Solve 50 problems rated 800–1000 on Codeforces
- Build anti-spiral habit

### Success Metric
Solve A and B in every Div. 4 round within 20 minutes combined.

---

## Stage 2 — Core Algorithms (1000 → 1400)
**Focus**: First real tools. Thinking patterns.

### Topics
- Prefix sums
- Two pointers
- Sliding window
- Binary search (on answer, not just arrays)
- Sorting with custom comparators
- Greedy with proof

### Goals
- Consistently solve Div. 3 A + B + C
- Solve 80 problems rated 1000–1400
- Attempt 15 Div. 3 rounds

### Success Metric
1200+ rating on Codeforces.

---

## Stage 3 — Data Structures + Graph Basics (1400 → 1700)
**Focus**: Standard structures. Graph intuition.

### Topics
- Stack, Queue, Deque
- Sets, Maps (and their ordered variants)
- BFS, DFS
- Basic tree problems
- Difference arrays

### Goals
- Solve Div. 3 D problems regularly
- Attempt 15 Div. 2 rounds
- Complete CSES Problem Set: Sorting & Searching + Graph sections

### Success Metric
1600+ rating. C++ transition begins here.

---

## Stage 4 — Dynamic Programming + Intermediate Graphs (1700 → 2000)
**Focus**: DP patterns. Graph algorithms.

### Topics
- DP: 1D, 2D, knapsack variants, bitmask intro
- Dijkstra, Bellman-Ford
- Topological sort
- DSU (Disjoint Set Union)
- Number theory: sieve, modular inverse

### Goals
- Solve Div. 2 C and D regularly
- CSES DP section complete

### Success Metric
1900+ rating.

---

## Stage 5 — Advanced (2000 → 2400)
**Focus**: Problem-specific. Gaps identified through contest data.

### Topics (determined by weaknesses at that stage)
- Segment trees, BIT (Fenwick)
- Advanced DP (trees, intervals, profile)
- Advanced graphs (flows, matching)
- Combinatorics
- Geometry (if needed)

### Goals
- Compete in Div. 1 rounds
- Consistent top 15% in Div. 2

### Success Metric
2400+ rating. Red.

---

## Python → C++ Transition
- **When**: ~1400 rating OR when TLE becomes a regular problem
- **Why**: Python is too slow for most problems above 1600
- **How**: Solve parallel problems in C++ during Stage 2. Don't switch cold.

---

## The Anti-Spiral Protocol (Always Active)
- 0–20 min stuck: Think only.
- 20–40 min stuck: Hints or first line of editorial only.
- 40+ min stuck: Full solution. Implement from scratch. Log the concept. Move on.
- NEVER research prerequisites mid-session. Log and address in structured blocks.
